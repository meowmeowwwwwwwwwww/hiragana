# Тетрадь хираганы — исходники

Для того, кто будет обновлять приложение (в том числе для Claude в новом чате).

- `app_template.html` — разметка, стили и логика приложения.
- `recognizer.js` — проверка рисунка, `stabilizer.js` — сглаживание линии (StreamLine),
  `puppy.js` — щенок, `pics.js` — картинки-ассоциации, `kana2.json` — эталоны черт (AnimCJK).
- `fonts/` — урезанные шрифты Klee One и M PLUS Rounded 1c (OFL).
- `icons/` — иконки приложения, `licenses.txt` — лицензии (копируются в корень при сборке).
- `sw_template.js` — service worker (работа без сети), `build.py` — сборка.

Сборка (из корня репозитория): `python3 src/build.py`. Она перезаписывает файлы сайта в корне
репозитория — `index.html`, `sw.js`, `manifest.webmanifest`, иконки и `licenses.txt` — и создаёт
`src/hiragana.html` (версия для Claude, в git не хранится). Версия в `sw.js` меняется при каждой
сборке, поэтому телефон сам подхватывает обновление. Файлы в корне руками не правь — только через сборку.

Выкладка: собрать, закоммитить исходники вместе с обновлёнными файлами в корне и запушить в `main` —
GitHub Pages раздаёт сайт из корня ветки `main`.

Прогресс хранится в localStorage под ключом `hiragana-notebook-v1` — не меняй ключ и формат
без переноса данных, иначе у пользователя пропадёт прогресс.
