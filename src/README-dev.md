# Тетрадь хираганы — исходники

Для того, кто будет обновлять приложение (в том числе для Claude в новом чате).

- `app_template.html` — разметка, стили и логика приложения.
- `recognizer.js` — проверка рисунка, `stabilizer.js` — сглаживание линии (StreamLine),
  `puppy.js` — щенок, `room.js` — комната щенка, `icons.js` — картинки к словам игр, `pics.js` — картинки-ассоциации, `kana2.json` — эталоны черт (AnimCJK).
- `fonts/` — урезанные шрифты Klee One и M PLUS Rounded 1c (OFL).
- `icons/` — иконки приложения, `licenses.txt` — лицензии (копируются в корень при сборке).
- `sw_template.js` — service worker (работа без сети), `build.py` — сборка.
- `make_icons.js` — рисует иконки из `puppy.js` в `icons/` (`node src/make_icons.js`, нужен playwright;
  путь к Chromium можно задать в `CHROMIUM_PATH`). После него — обычная сборка.

Сборка (из корня репозитория): `python3 src/build.py`. Она перезаписывает файлы сайта в корне
репозитория — `index.html`, `sw.js`, `manifest.webmanifest`, иконки и `licenses.txt` — и создаёт
`src/hiragana.html` (версия для Claude, в git не хранится). Версия в `sw.js` меняется при каждой
сборке, поэтому телефон сам подхватывает обновление. Файлы в корне руками не правь — только через сборку.

Выкладка: собрать, закоммитить исходники вместе с обновлёнными файлами в корне и запушить в `main` —
GitHub Pages раздаёт сайт из корня ветки `main`.

Прогресс хранится в localStorage под ключом `hiragana-notebook-v1` — не меняй ключ и формат
без переноса данных, иначе у пользователя пропадёт прогресс.

Питомец (`S.pet`): звёзды `stars`, конпэйто `kp` (редкая валюта), капсульный автомат `gacha` ({ n, pity }),
вещи `owned`/`wear` (на одно место — одна вещь, места в `SLOT_OF`), `wgame`/`wordBest` — звёзды за день и рекорд игры «Заказы», `cw`/`cwday` — текущий кроссворд и награды за день, `cwSeen` — сколько раз каждое слово попадалось в кроссворд (слова — `CW_WORDS`, список из учебника; слова без общих знаков встают отдельными островками), `kpDay`/`kpStreak` — чтобы бонусы
за повторение и серию дней не выдавались дважды. Рисунки вещей, окрасов и фонов — в `puppy.js`. Комната — `room` ({ owned, on }), вещи в `ROOM_ITEMS`, уют замедляет грусть.

Урок 13 «Цифры» (`kind: "numbers"`): порции `NUM_GROUPS` (1–5, 6–10, большие), для каждой — знакомство с подсказкой
`NUM_MNEMO`, узнавание с выбором ответа, письмо; между ними правила и сборка составных чисел. Составные числа
генерирует `numToks(n)` (с особыми さんびゃく, ろっぴゃく, はっぴゃく, さんぜん, はっせん, いちまん). Место в уроке
(`S.lessons[n].resume`) помечено `nv: 2`; сохранения старой версии урока чисел игнорируются.

«Слова к тесту» (`startVocab(mode)`, панель `vocabPanel()` на главной): 20 слов учебника `VOCAB_WORDS` (их же берёт кроссворд).
Режимы: `learn` — порции по 5 (знакомство с подсказкой `mn`, выбор ответа, сборка из слогов, письмо), ловушки `trap`
и все слова вперемешку; `review` — 10 самых слабых слов (или ошибки теста); `test` — 20 вопросов без повторов.
Состояние `S.vocab`: `lv` — уровень слова 0…5 (3+ — выучено), `resume` — место в `learn`, `best`/`last` — тест.
Неверные варианты написания даёт `vSpellings(w)`.
