# Тетрадь хираганы 🍓

Розовая тетрадь, в которой ты учишь хирагану: рисуешь знаки пальцем по рукописным образцам,
а щенок Кинако проверяет и подбадривает. Работает без интернета.

**Открыть:** https://meowmeowwwwwwwwwww.github.io/hiragana/

## Как поставить на iPhone

1. Открой ссылку выше в **Safari**.
2. Нажми «Поделиться» (квадрат со стрелкой вверх).
3. Выбери **«На экран „Домой“»** и нажми «Добавить».

Тетрадь появится на экране «Домой» как обычное приложение и будет открываться даже без сети.
Прогресс хранится на самом телефоне.

## Для разработки

Исходники лежат в [`src/`](src/), описание — в [`src/README-dev.md`](src/README-dev.md).
Сборка: `python3 src/build.py` — обновляет файлы сайта в корне репозитория.
